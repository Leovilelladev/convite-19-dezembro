# Convite 19 de dezembro

Landing page em formato de convite, criada para a atividade da EBAC.

## Sobre o projeto

A página usa a data de aniversário, 19 de dezembro de 2003, como tema visual e textual. Foi feita com HTML, CSS e JavaScript puro.

## Como abrir

Abra o arquivo `index.html` no navegador.

## O que foi usado

- HTML semântico
- CSS responsivo
- JavaScript para menu mobile e confirmação de presença
